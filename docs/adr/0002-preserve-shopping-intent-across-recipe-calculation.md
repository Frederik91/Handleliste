# Preserve shopping intent across Recipe calculation

Recipe planning will capture the Planned Supply present when the first Recipe is selected and add separately tracked packages only for any shortfall. Later manual or Always in Stock additions will not cause those Recipe-generated packages to disappear, because they represent additional household intent; removing or reducing Recipes may remove only quantities generated by Recipe calculation. This requires provenance and relative manual adjustments, but avoids surprising continuous optimization that silently removes items the household deliberately added.
